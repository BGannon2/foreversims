**Forever client build 70205 — v0.33.0 is live**

**Druid (Feral)**
• King of the Jungle is now Shifting Power: instantly turns Mana into 40 Energy (16 sec cooldown). New talent Improved Shifting Power cuts the cooldown to 8 sec. Cat Form now tracks your Mana pool for it.
• Default Cat setup: +13.4% DPS.

**Warrior**
• Dual Wield Specialization no longer increases off-hand Rage (it keeps its off-hand damage and hit).
• Default setups: Fury −7.4%, Arms −6.6% DPS. The Fury changes from the latest Wowhead post (Bloodthirst, Whirlwind, crit Rage) aren't in the client data yet — they'll follow when that build lands.

**Paladin**
• Champion of the Light: spell power from 20/40/60% of Intellect (was 33/66/100%). Retribution −2.2%.
• Redoubt: +4% block per rank (was 6%).

**Hunter**
• Improved Serpent Sting was removed from the game; the default Beast Mastery and Marksmanship builds re-spend those points (Marksmanship +2.9%).

**Also:** talent trees now sync their layout and prerequisites straight from the game client.
