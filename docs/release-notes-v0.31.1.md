**Warrior rage update from the Forever class deep dive — v0.31.1 is live**

**Warriors**
• Critical auto-attacks now give 75% more rage than normal hits.
• Rage from taking damage ignores armor: it's calculated as if you always had 50% armor reduction, so more armor no longer means less rage.
• Default setups: Arms +4.7% DPS, Fury +5.4% DPS, Protection +7.7% threat.
• Warrior "Assumed Forever BiS" sets rebuilt.

**Not changed yet:** Bear rage still uses the Classic formulas, and changes the post gives no numbers for (Sunder Armor and Thunder Clap attack power scaling, Bloodthirst, Flurry) wait for data.
