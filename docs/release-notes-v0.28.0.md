**Cleaner BiS sets for Phase 1–2 — v0.28.0 is live**

**Ahn'Qiraj and later-raid gear removed from BiS sets**
• Some later-phase gear was getting into the "Assumed Forever BiS" sets because its item source was listed as a world drop or an ordinary quest: AQ40 class sets (Conqueror's, Avenger's, Deathdealer's…), Blessed Qiraji weapons, AQ20 quest rewards, Brood rings, Earthstrike, and Molten Core drops like Talisman of Ephemeral Power.
• Sets now check each item's real drop zone and content phase against the WoWSims item database, and skip anything from later raids or the AQ patch onward.
• Expect most sets to drop 1–8%, since they had been counting gear from later phases.

**Tank armor types**
• Protection Warrior and Protection Paladin BiS sets use only plate armor, and Bear sets only leather (jewelry, cloaks and trinkets are unaffected).

Validation: 139 tests, and Python and Rust results match on all 23 specs.

**Still early alpha:** some Forever mechanics and gear sources are unconfirmed; assumptions are shown in results.
