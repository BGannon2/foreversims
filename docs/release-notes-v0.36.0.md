**Spec variants — v0.36.0 is live**

**New builds on the DPS and Tank comparison pages**
• Fury-Prot, Ret-Prot and Holy-Prot tanks; Shockadin; Survival (Melee Weave); Elehance; Frostfire.
• Each has sim-optimized talents and its own BiS set. On a spec page, pick one from the new **Build** menu in the talent area.

**Engine**
• Holy Shock added for Paladins (Shockadin, Holy-Prot).
• Frostfire Bolt now counts as both Frost and Fire, so Ignite, Fire Power, Improved Scorch and Combustion apply to it.
• Hunter pet abilities now use Forever client values: Bite 81–99, Lightning Breath 86–98, Screech 24–42 (10 sec cooldown).
